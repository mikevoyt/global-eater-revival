# What we can build next

Global Eater 0.1 is a working starting point for collaboration. The aim is to try it together, make small useful improvements, and eventually build something worth sharing more widely. These are possible directions to choose together, not commitments or deadlines.

## Try the Android app together

The Pixel build is working. Complete the [manual acceptance checklist](TESTING.md): saved entries after relaunch, offline use, large text, navigation, and accessibility. Turn surprises into small issues with clear reproduction steps. Measure startup and search responsiveness before adding dependencies.

## Make the food dictionary more trustworthy

Review eight duplicate-name groups without breaking stable IDs or saved entries. Check legacy romanization and definitions through an editorial override layer, keeping the recovered archive intact. Review the 180 draft additions and improve entry-by-entry references.

## Bring iOS through the same validation

Build the generated iOS host, try the simulator, then test signing, navigation, text scaling, and storage on an iPhone. The guide describes the route; an iOS build is not yet verified. Decide separately whether to reuse the original App Store identity.

## Explore a few small ideas

- Saved-list export and import.
- A “want to try / tried” food passport.
- Curated pronunciations.
- Optional menu-camera lookup.
- Properly licensed food photographs and higher-resolution original artwork.

Keep the offline dictionary useful without a paid API or account. Agree on content/artwork permissions and distribution choices before a wider release.
