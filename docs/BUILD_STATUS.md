## Repeat the checks

See [the beginner guide](BEGINNER_GUIDE.md) for tool setup. From the project folder:

```bash
python3 -m unittest discover -s tool -p 'test_*.py' -v
bash scripts/android.sh --build-only
```

The Android script runs native setup, catalog validation, dependency resolution, static analysis, Flutter tests, and APK compilation. It records the APK checksum and Flutter version under the ignored `dist/` folder. Installation is a separate explicit step when using `--build-only`.
